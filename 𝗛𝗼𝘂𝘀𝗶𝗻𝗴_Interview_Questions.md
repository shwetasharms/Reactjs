### localStorage vs sessionStorage

| Feature            | localStorage     | sessionStorage         |
| ------------------ | ---------------- | ---------------------- |
| Persistence        | Permanent        | Session-based          |
| Shared Across Tabs | Yes              | No                     |
| Storage Limit      | ~5-10 MB         | ~5-10 MB               |
| Use Case           | User preferences | Temporary session data |

# Final Takeaway

Success in frontend interviews is not just about knowing React or JavaScript APIs.

Interviewers often evaluate:

* Problem-solving approach
* Architectural thinking
* Trade-off analysis
* Ownership mindset
* Communication skills

The strongest candidates explain not only **what** they built, but also **why** they built it that way.
